# Archive des livraisons de Micro-Rider

Chaque dossier est un instantané des fichiers modifiés à une livraison (ils ne contiennent que les fichiers qui ont changé ce jour-là, pas tout le projet).
Les noms des fichiers gardent leur nom d'origine suivi du numéro de livraison (`app_r5.js` = `js/app.js` à la livraison r5).
Règle (demandée par Florent le 2026-10-26) : avant d'écraser un fichier du projet, on archive l'ancienne version ici. On ne supprime rien.

- `liv`, `liv2`, `liv3`, `liv4` et les fichiers `*_r2`, `decisions_v4.md` : premières livraisons du 2026-10-25/26 (page `micro-rider.html`, premiers modules).
- `r3` … `r9` : livraisons suivantes (Click, rapports, sortie .tcx, ERG, joystick/frein/boost, mémoire Bluetooth…). Le contenu de `r10` est la version actuelle du projet : il n'est pas archivé.
- Les notes de décisions de chaque étape sont dans `decisions_*.md` ; la version à jour est `code/docs/decisions.md`.
