# Micro Rider — Parallaxe 2D

Ouvrir index.html directement dans le navigateur. Tout est local, sans dépendance réseau.

Deux ambiances originales : côte ensoleillée et ville électrique. Décor dessiné dans le canvas avec plusieurs vitesses de défilement. Cycliste de profil au tiers gauche, issu de la séquence de pedalage-anime.png acceptée pour les tests : la même planche source est lue image par image pour régler la cadence et permettre la pause. Les imperfections de cette séquence de test sont conservées.

Vitesse et cadence sont indépendantes. Il s’agit d’une simulation visuelle, sans connexion BLE, sans physique ni mesure de distance réelle. La distance du HUD est indicative.

Contrôle effectué par simulation JavaScript : deux ambiances, lecture des sprites, pause et commandes. Pas de vérification interactive dans le navigateur.
