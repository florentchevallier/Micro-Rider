# Micro Rider Pocket — compositions initiales

Deux compositions de la même coque portable, sans modification des prototypes existants.

- Classique : fenêtre 274 × 235 unités dans une coque de 360 × 580.
- Grand écran : fenêtre 318 × 332 ; les commandes sont déplacées plus bas, sans agrandissement.
- Boutons A/B : diamètre 31 unités (8,6 % de la largeur), proche des boutons de la borne 90s (environ 8,3 %).
- Croix : silhouette monobloc à quatre directions, logements indépendants du contenu de l’écran.
- La coque et le contenu sont construits séparément ; les fichiers SVG décrivent la composition, les zones de clic sont des boutons HTML superposés.
- Flèches = croix ; Z = B ; X = A ; Entrée = Start ; Maj = Select. Mapping manette standard via Gamepad API : croix ou stick gauche, boutons 0/1, Start 9, Select 8. Compatibilité des manettes réelles à vérifier dans le navigateur cible.
- Les boutons sont cliquables et réagissent aussi au clavier. Le contenu de séance est une illustration fixe : aucune connexion au home trainer, aucune simulation de mouvement.
- L’écran reste en couleur ; aucune contrainte LCD monochrome n’est imposée.

Vérification : rendu des deux compositions en PNG, contrôle des espaces entre commandes et fenêtre, vérification syntaxique des scripts. Le contrôle interactif des pages locales par l’outil navigateur est indisponible dans cette session.

Illustration d’écran : recadrage de l’aperçu asphalte déjà validé. Le rendu de coque est du SVG natif, sans nouvelle génération d’images.
