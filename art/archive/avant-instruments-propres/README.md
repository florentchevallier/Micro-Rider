# Micro Rider — studio visuel

Ouvrir index.html directement dans un navigateur.

- assets/bornes : illustrations originales pour le mode menu.
- assets/bornes-jeu : retouches illustrées pour le grand écran, réalisées avec imagegen intégré à partir de chaque borne originale. Montants continus, aucune texture répétée et aucun montant vectoriel.
- assets/jeux : les sept décors.
- ../archive : versions de travail et essais écartés.

Le bouton Mode jeu choisit un rendu illustré complet adapté, sans étirement des montants. Les chiffres et instruments restent animés en superposition. Les décors sont fixes et les mesures simulées. Les aiguilles peintes des cadrans steampunk restent présentes dans les images.

Prompt de retouche employé pour chaque borne : conserver exactement le style réaliste/cartoon peint, les matières, la lumière, les reflets, l’usure, l’enseigne et les commandes de l’original ; supprimer le pied ; placer la console en bas et prolonger naturellement les montants avec un grand écran vertical vide ; ne répéter aucun motif, groupe de vis, tuyau ou raccord ; ne pas simplifier en vectoriel ni ajouter de décoration. Rendu frontal portrait 2:3. Références : les cinq images originales de assets/bornes.
